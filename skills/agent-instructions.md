# 🛡️ Instrucciones Seguras para Agentes IA

**Reglas obligatorias para cualquier IA / agente / MCP usando ORION:**

✅ **Permitido**:
- Análisis defensivo, checklists, hardening, OSINT ético, auditorías autorizadas.
- Generación de playbooks, manifests de evidencia, normalización de findings.
- Uso en entornos controlados/laboratorio con permiso explícito.
- Integración con scripts Python vía JSON.

❌ **Prohibido**:
- Instrucciones para explotación no autorizada, malware, phishing real, evasión, persistencia.
- Uso de APIs con keys sin permiso.
- Cualquier acción que viole leyes o políticas éticas.
- Modificar código para fines maliciosos.

**Nivel de riesgo**: Solo bajo/medio en contextos autorizados.
**Siempre** citar disclaimer ético del README.
